# Requirements

This directory contains the Python package requirements for the Convocacao project.

## Files

- `base.txt` - Core dependencies required for all environments
- `local.txt` - Additional dependencies for local development
- `production.txt` - Additional dependencies for production deployment

## Usage

### Local Development
```bash
pip install -r requirements/local.txt
```

### Production
```bash
pip install -r requirements/production.txt
```

### Base Only
```bash
pip install -r requirements/base.txt
```
